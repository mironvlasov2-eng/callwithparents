# Call With Parents - Бесплатные видеозвонки 1 на 1

Веб-приложение для видеозвонков 1 на 1 с использованием WebRTC технологии. Полностью бесплатное решение без необходимости в серверах для передачи видео/аудио.

## 🚀 Особенности

- **Бесплатное использование** - никаких подписок или ограничений
- **Peer-to-peer соединение** - данные передаются напрямую между участниками
- **Современный интерфейс** - красивый и интуитивный дизайн
- **Мобильная адаптация** - работает на всех устройствах
- **Управление медиа** - включение/выключение видео и микрофона
- **Автоматическое подключение** - простое создание и присоединение к комнатам

## 🛠 Технологии

- **HTML5** - структура приложения
- **CSS3** - современные стили с градиентами и анимациями
- **JavaScript (ES6+)** - логика приложения
- **WebRTC** - технология для peer-to-peer соединений
- **PeerJS** - библиотека для упрощения работы с WebRTC

## 📱 Как использовать

### 1. Создание комнаты
1. Откройте приложение в браузере
2. Нажмите "📞 Создать комнату"
3. Разрешите доступ к камере и микрофону
4. Поделитесь ID комнаты с собеседником

### 2. Присоединение к комнате
1. Нажмите "🔗 Присоединиться"
2. Введите ID комнаты, полученный от собеседника
3. Нажмите "Присоединиться"
4. Разрешите доступ к камере и микрофону

### 3. Управление звонком
- **📹** - включить/выключить видео
- **🎤** - включить/выключить микрофон
- **📞 Завершить звонок** - завершить соединение

## 🔧 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd callwithparents
   ```

2. **Откройте в браузере:**
   - Просто откройте `index.html` в любом современном браузере
   - Или используйте локальный сервер для лучшей производительности

3. **Для локального сервера (рекомендуется):**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (если установлен)
   npx http-server
   
   # PHP
   php -S localhost:8000
   ```

4. **Откройте в браузере:**
   ```
   http://localhost:8000
   ```

## 🔒 Безопасность

- Все соединения зашифрованы
- Данные не проходят через серверы
- PeerJS используется только для установки соединения
- Видео и аудио передаются напрямую между участниками

## 🚨 Устранение неполадок

### Не работает видео/аудио
- Убедитесь, что браузер имеет доступ к камере и микрофону
- Проверьте настройки приватности браузера
- Попробуйте обновить страницу

### Не удается подключиться
- Проверьте интернет-соединение
- Убедитесь, что ID комнаты введен правильно
- Попробуйте создать новую комнату

### Плохое качество связи
- Проверьте скорость интернета
- Закройте другие приложения, использующие камеру
- Попробуйте переподключиться

## 📞 Поддержка
